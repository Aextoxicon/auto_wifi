# eureka

一个适用于高技校园网的自动登录应用程序，基于flutter开发

**支持平台**

Android、Windows、macOS

**使用方法**

[下载地址](https://github.com/Aextoxicon/eureka/releases/)
↑或者是直接去仓库的release页面下载，都是一样的地方

Android：
- 启动应用程序，会提示申请通知权限以及要求申请电池优化白名单，全部同意即可（不然不保证软件在后台自动登录稳定性）
- 先输入账号密码→开始任务
- 第一次启动可能依旧会弹出校园网认证页面，大概率是正常情况（弹出来的时候大概率是已经登录的状态
- 启动服务的时候软件会在后台持续运行以及显示通知
- 退出软件建议自己去App在设置里面的管理页面或者是点击“跳转设置强行停止APP”
- 检查更新请求的是GitHub API的release tag，使用了gh-proxy一般情况下没有问题
- 软件更新安装包是调用系统自带浏览器下载，下载完了去浏览器下载页面或者是文件管理器去安装新版本安装包，如果安装失败卸载旧版本即可

Windows、macOS：
- 下载对应的压缩包
- Windows是绿色版（懒得做安装程序），直接运行里面exe就行
- macOS解压后是app文件，可以选择直接运行或者是拖到Applications里面
- 配置逻辑和上面Android版本同理，不过软件在这两个版本不会去申请其他权限，直接关闭窗口服务就会完全退出
- 自动更新部分同理，但是不像Android是自动安装，仅仅是提醒去release页面下载

**Android权限申请及其原因**
- 通知权限：用于前台服务提升程序优先级，防止后台被杀
- 申请电池优化白名单：防止APP被系统作为后台省电服务杀
- 至于为什么Android推荐用系统强行停止因为软件后台服务运行在dart lsolate里面，无法在Android通过APP信号杀死，只能通过系统信

**注意事项**
- 启动软件时不能启动其他代理进程不然服务的运行容易出问题
- 软件可能会被系统标记为高耗电应用，实际上软件功耗不高，并且对后台占用基本上很低
- 不直接填好公共账号是因为不保证以后这个账号密码会不会变
- 目前只保证在gjjgxx校园网正常登录

**特点**
- 原生支持Android预见返回手势
- 后台保活用的是Android官方推荐且规范的做法，确保日后稳定运行
- 截至2026.03.07，软件最新可以在Android Cinnamonbun(17)稳定运行

*目前软件基本上趋近于稳定版本，基本上不会有更新，因为是我个人开发精力有限，但是我会尽量保证核心功能可用性*
