# eureka

一个适用于高技校园网的自动登录应用程序，基于 flutter 开发

**支持平台**

Windows、macOS、Linux

**使用方法**

[下载地址](https://github.com/Aextoxicon/eureka/releases/)
↑或者是直接去仓库的release页面下载，都是一样的地方

Windows、macOS、Linux：
- 下载对应的压缩包
- Windows是绿色版（懒得做安装程序），直接运行里面exe就行
- macOS / Linux 解压后直接运行
- 配置逻辑简单，关闭窗口服务就会完全退出
- 自动更新会提醒去release页面下载

**注意事项**
- 启动软件时不能启动其他代理进程不然服务的运行容易出问题
- 目前只保证在 gjjgxx 校园网正常登录

**特点**
- 原生跨平台桌面支持
- 轻量后台运行

**测试设备**
- Windows 11 Pro
- macOS Monterey
- Linux (Ubuntu)

**涉及技术栈**
- flutter
- GitHub CI/CD
